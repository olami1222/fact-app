# 🐾 Fact App – HNG Stage 0 Backend Task

A simple RESTful API built for **HNG Internship Stage 0**.  
The `/me` endpoint returns your profile details along with a random cat fact fetched dynamically from the [Cat Facts API](https://catfact.ninja/fact).

## 🧠 Features
- Returns profile information in JSON format  
- Fetches a random cat fact dynamically from the Cat Facts API  
- Includes a dynamic UTC timestamp (ISO 8601 format)  
- Gracefully handles API errors  
- Hosted live on [Railway](https://railway.app)

---

## 🧰 Tech Stack
- Node.js
- Express.js
- Axios (for external API calls)
